# Competitions CODEX 2026

Kompetisi CODEX 2026 diadakan untuk dua bidang lomba, yaitu [_Competitive Programming_](./cp.html) dan [_Capture The Flag_](./ctf.html). Kompetisi diadakan untuk mahasiswa aktif Universitas Brawijaya angkatan 2024, 2025, atau 2026 secara individu pada tanggal 28 September - 4 Oktober 2026. Pendaftaran dibuka pada tanggal 00 September - 00 September 2026 pada URL berikut: [http://clips.my.id/FormRegistrasiKompetisiCodEx2026](http://clips.my.id/FormRegistrasiKompetisiCodEx2026).
